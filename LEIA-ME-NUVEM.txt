PRIME GESTÃO V10 — BANCO ÚNICO COMPARTILHADO

O motivo de cada navegador ver dados diferentes é que o localStorage pertence a cada navegador.

Na V10 a nuvem é obrigatória e passa a ser a fonte principal.

PASSOS:
1. Publique google-apps-script/Code.gs como Aplicativo da Web no Apps Script.
2. Copie a URL que termina em /exec.
3. Abra cloud-config.js.
4. Cole a URL em webAppUrl: "SUA_URL_EXEC".
5. Salve e envie cloud-config.js para o GitHub.
6. Todos os usuários passam a abrir o mesmo banco; cada navegador informa apenas o PIN da equipe.

A V10:
- bloqueia o uso se a nuvem não estiver configurada;
- baixa os dados mais recentes antes de liberar a tela;
- salva cada alteração imediatamente na nuvem;
- verifica alterações de outros usuários a cada 5 segundos;
- possui botão Sincronizar agora;
- mantém backup por e-mail.

NÃO coloque o PIN no GitHub.
